# L1

Static page. Tap Fetch and the browser pulls the latest SWPC mag and plasma files, then builds the paste. There is no server and no saved copy of the data in the repo. If you do not open it for a week, the next tap is still live.

## Put it on GitHub Pages

1. Create an empty public repository.
2. Upload everything in this folder to the repository root: `index.html`, `app.js`, `rtsw.js`, `styles.css`, `.nojekyll`.
3. Settings → Pages → Build and deployment → Deploy from a branch → `main` and `/ (root)`. Save.
4. Open the Pages URL and tap Fetch.

Do not open `index.html` as a file on your computer. The browser blocks that. GitHub Pages is the host.
